01

模块 A · 开场引入

MODULE A · OPENING
A

放下紧张感 · 回到"当年那个我"

2 题 · 5-8 分钟
Q1 · 5min 导入 · 时空定位 建议首问

你哪一年加入新港？当时 30 岁 / 23 岁 / 28 岁的你，是怎么走进新茂路 8 号那扇门的？

提问意图
让对方回到具体时空细节；「30 岁的我」这种代入感比「我加入新港」更容易打开话匣子。
期望画面
大二普草甸中景，面朝雪山；不急，让他们先回忆、停顿。
建议 不用反光板，让自然光给出层次。
期望方向
具体到年份 / 季节 / 当天的画面（"那年夏天" / "穿着什么衣服" / "谁面试的我"）。
剪辑用法
开场第一镜 · 字幕叠加 「新港 25 年 · 传承」。
Q2 · 3min 对比 · 初心 vs 现在

你最初被新港吸引的是什么？现在回头看，那种吸引力变了吗？

提问意图
捕捉「初心 vs 现在」的对比，自然带出传承的内在张力——变化的是工具，不变的是什么。
期望画面
老员工走动 / 转身，镜头跟住；草甸风动 + 雪山背景虚化。
期望方向
希望听到具体的人 / 具体的话 / 具体的画面，不是抽象的"企业文化"。
剪辑用法
与 Q5「传下去什么」形成首尾呼应。
02

模块 B · 传承核心

MODULE B · HERITAGE
B

具象化"传承"的动作与瞬间

3 题 · 10-15 分钟 · 情绪最重
Q3 · 5min 核心 · 动作化 80% 出金句

在新港这些年，你印象最深的一次「交接」是什么？

提问意图
让"传承"具象到一个动作（递扳手 / 签合同 / 教客户开车 / 带徒弟）。
期望画面
特写手部 + 远景雪山背景叠化（用后期做画面交叉剪辑）。
期望方向
具体到「交接给了谁」+「交的是什么」+「那一刻你在想什么」。
剪辑用法
传承主题核心金句来源；80% 的概率会出"年度最佳金句"。
🔁 三层追问 · 备好不出声 L1 你当时具体做了什么动作？
L2 那一刻你脑子里在想什么？
L3 如果回到那天，你会改变什么吗？
Q4 · 5min 核心 · 自我确认

有没有哪个瞬间，你突然觉得「新港的精神在我手里了」？

提问意图
捕捉传承的"自我确认"瞬间——不是被授予，而是接住了。
期望画面
长焦特写眼神 + 自然光 · 安静 · 不打断。
期望方向
希望对方讲具体的一个瞬间（比如"那次客户出了事故我半夜赶到现场"）。
剪辑用法
主题高潮 · 情绪拐点 · 配乐升 key 节点。
Q5 · 5min 核心 · 价值观锚定

你最想把新港的什么「传」给下一代新港人？

提问意图
定义"传承什么"，让对方主动表达价值观。
期望画面
老员工面朝镜头，慢推近景；后景大二普雪山日落（如果天气允许）。
期望方向
希望听到非物质层面的（"客户第一" / "靠谱" / "责任"），而不是设备 / 技术。
剪辑用法
全片主旨句 · 片尾字幕叠加。
03

模块 C · 25 年故事钩子

MODULE C · STORIES
C

用故事代替评价 · 用客户代替群体

3 题 · 10-12 分钟 · 戏剧性张力
Q6 · 4min 钩子 · 危机转折

新港这 25 年里，你印象最深的一次「危机或转折」是什么？当时你做了什么？

提问意图
让历史有戏剧性张力；同时映射"品牌经得起时间"的隐喻。
期望画面
大二普溪流旁，老员工侧脸逆光，水声作为环境音。
期望方向
希望听到 2008 金融危机 / 2020 疫情 / 某次政策变化 / 某次客户维权等的具体故事。
剪辑用法
可剪独立短片「风暴中的力量」30 秒版本，社媒二次传播。
Q7 · 4min 钩子 · 客户故事

有没有哪个客户的故事，到现在还常常想起？

提问意图
用"具体一个人"代替"客户群体"，让品牌人性化。
期望画面
特写手部（握着咖啡杯 / 翻相册），景深虚化远山。
期望方向
希望是"陪客户走了 10 年"的长期故事，而不是一次性交易。
剪辑用法
「我们服务的不只是车，是人」品牌温度佐证。
Q8 · 4min 钩子 · 变与不变

你见证过的「最大变化」是什么？不变的是什么？

提问意图
制造对比，凸显"变的部分是工具，不变的是精神"。
期望画面
老员工走路 / 看远方，自然过渡。
可剪一镜到底跟拍。
期望方向
希望听到"客户从燃油车到新能源" / "展厅从 1 家到 N 家" / "我自己从销售到管理"等。
剪辑用法
与 Q5「传下去什么」形成结构性呼应。
04

模块 D · 画面配对

MODULE D · LOCATION
D

外部自然 ↔ 内部品牌记忆的意象缝合

2 题 · 6-8 分钟 · 必在北段点位实地
Q9 · 4min 配对 · 自然 ↔ 记忆 红石滩 / 理小隧道 / 大二普

你现在看着这片山河，你想起在新港的哪个时刻？

提问意图
把外部自然景观与内部品牌记忆链接起来，制造"穿越"的诗意感。
期望画面
航拍大景 → 切到人物特写（人在天地间的渺小感）。
建议航拍 + 手持双机位。
期望方向
希望对方自己产生联想（"这种开阔" / "这种红" / "这种穿透感"），不强求。
剪辑用法
全片视觉高潮·空镜与口述交织 · 配乐升 key。
Q10 · 4min 配对 · 意象缝合 雷神王瀑布 / 红石滩 / 大二普

你觉得这种「时间穿过自然」的感觉，和新港 25 年的「时间穿过团队」有什么相通的地方？

提问意图
把自然意象与品牌主题做一次意象缝合。
期望画面
长焦侧逆光 · 人物剪影 · 光影穿过发丝。
如果光线对，能出"年度最佳镜头"。
期望方向
希望听到对方自己的感悟，不强求"标准答案"。
剪辑用法
片尾收束金句 · 全片主旨升华。

模块 E · 收束金句

MODULE E · CLOSING
E

留给观众带走的最后一句

1 题 · 2-3 分钟 · 全片最后一镜
Q11 · 2-3min 收束 · 未来寄托 必问 · 留金句

如果用一句话，送给新港的下一个 25 年，你会说什么？

提问意图
定义"未来寄托"·给观众一句带走的。
期望画面
黑起 / 淡入字幕 · 人物最后一个画面定格。
无干扰，最纯粹的镜头。
期望方向
希望短小 · 金句感 · 可被引述（10-30 字内）。
剪辑用法
全片最后一镜 · 字幕卡 · 社媒传播的核心句。

08

访谈技巧与避坑

INTERVIEW TIPS

✅ 应该做

  • 从「你当时 30 岁那会儿」切入·代入感打开话匣子
  • 问具体年份 / 人物 / 画面·让答案带画面
  • 给 5-8 秒的沉默缓冲·不要急，停顿出金句
  • 准备三层追问（做了什么 / 怎么想 / 回到那天会改变吗）
  • 先看对方简历·避免问已说过的事
  • 纪录片感·不用大灯 / 不用反光板硬光
  • 拍摄前聊 10 分钟·建信任 · 让对方忘记镜头

⚠️ 避免做

  • 不问大道理（"您觉得新港精神是什么"——对方只能背词）
  • 不让对方感觉在"被采访"·从"当年那个我"切入
  • 不打断沉默·5-8 秒停顿里常常出真话
  • 避免禁忌话题·行业敏感事件 / 在任高管评价 / 人事变动
  • 不要追求"漂亮话"·真实感 > 完美感
  • 不在疲劳 / 饥饿 / 高反时硬拍·情绪影响答案
